
# 🎬 Netflix Clone

A responsive Netflix landing page clone built using **HTML5** and **CSS3**. This project replicates the look and feel of Netflix's homepage, focusing on modern UI design and responsive layouts.

## 🚀 Live Demo

🔗 [https://saicharan-devoju.github.io/Netflix-clone/](https://saicharan-devoju.github.io/Netflix-clone/)

## ✨ Features

- Netflix-inspired user interface
- Fully responsive design
- Hero section with background banner
- FAQ section
- Mobile-friendly layout
- Clean and organized code structure

## 🛠️ Tech Stack

- HTML5
- CSS3
- Flexbox
- Media Queries
